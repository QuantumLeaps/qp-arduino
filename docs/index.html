qp-arduino documentation

The manuals that match each release of the library.

qp-arduino packages one specific version of the QP/C++ real-time embedded framework for Arduino boards. The QP/C++ API, the QM modeling tool and the QTools host tools all change between QP versions, and the upstream sites document only the newest one. This page keeps the manuals that match each qp-arduino release, so a sketch written against the library can be checked against the right text.

qp-arduino 7.3.4

Released 2026-10-04. QP/C++ 7.3.4 with the QV kernel and QS tracing; qualified on RP2040 with the arduino-pico core.
